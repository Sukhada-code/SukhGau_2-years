## Features

- Personal 2-year anniversary landing page
- Real photo timeline + gallery
- "Kiss me" button with 💋 / 😘 / ❤️ / 💗 floating kisses
- Sparks by Coldplay music section
- Interactive drawing canvas
- Personalized anniversary letter
- Responsive mobile layout

## The song

The music card links to the official Coldplay/YouTube audio for **Sparks**. The copyrighted audio file is not bundled.

If you later want the site to play a local copy, place your legally obtained file at:

`assets/sparks.mp3`

and the music section can be switched to local playback.

## Run

No build tools are required. Open `index.html` in a browser.

## Editing later

All text is in `index.html`, styling is in `style.css`, and interactions are in `script.js`.
